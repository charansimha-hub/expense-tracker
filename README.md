# 💰 ExpenseWise — Smart Expense Tracker

A beautiful, fully client-side expense tracking web app with smart savings suggestions and investment advice. No backend needed — runs entirely in your browser.

![Dashboard](https://img.shields.io/badge/Status-Live-brightgreen) ![License](https://img.shields.io/badge/License-MIT-blue) ![No Backend](https://img.shields.io/badge/Backend-None-orange)

## ✨ Features

- 📊 **Dashboard** — Summary cards, category charts, spending trends
- ➕ **Quick Add** — One-tap buttons for common expenses (tea, lunch, bus, petrol)
- 📅 **Daily / Weekly / Monthly Views** — Filter and browse all transactions
- 📈 **Analytics** — Pie charts, bar charts, month-over-month comparisons
- 🎯 **Budget & Savings** — Set income, savings targets, per-category budgets
- 🧠 **Smart Advisor** — Personalized reduction suggestions with potential savings
- 💡 **8 Savings Tips** — 50/30/20 rule, 24-hour rule, meal prep, and more
- 📈 **Investment Suggestions** — PPF, SIP, FD, RD, NPS, Gold with risk ratings
- 💾 **Export / Import CSV** — Backup and restore your data
- 🌙 **Dark Theme** — Beautiful dark UI with smooth animations
- 📱 **Responsive** — Works on desktop, tablet, and mobile

## 🛠️ Setup

No build tools or server required. Just open `index.html` in a browser.

### Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch** → `main` → `/ (root)`
4. Your site will be live at `https://<username>.github.io/expense-tracker/`

## 💡 How It Works

- All data is stored in your browser's **localStorage**
- No account, no server, no database — 100% private
- Works offline after first load (CDN assets cached by browser)
